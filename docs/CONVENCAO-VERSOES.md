# Convenção de versões — Soberania

A partir da versão 0.83, pequenas correções podem usar três casas decimais na identificação exibida ao jogador:
- 0.83: versão atualmente publicada.
- 0.831, 0.832, ..., 0.839: refinamentos da série 0.83.
- 0.84: marco funcional seguinte.
- 1.00: reservado para o lançamento oficial, somente quando aprovado.

Ao publicar, sincronizar `src/config/version.js` com o `package.json` (exemplo: exibição `0.831`, versão técnica `0.831.0`) e adicionar o registro em `docs/versao-0.831.md`.

Não mudar a versão apenas para registrar esta convenção. O próximo ajuste jogável será 0.831.
