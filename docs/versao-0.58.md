# Game Soberana v0.58 — cinematografia da primeira noite

- Após vencer a onda zero na campanha (não no modo de teste), uma nave superior surge na parte superior da tela.
- A nave se aproxima lentamente, prepara o núcleo vermelho, dispara um feixe contra a posição do canhão; impacto e tremor de câmera precedem o plantão Cubo News anunciando a destruição.
- A sequência segue para o boteco com a campanha preservada e cinco conselheiros. Texto do boteco foi encurtado para não duplicar a cena.
- Cena é feita com primitivas Phaser, sem PNG adicional; substituição futura por sprites e efeitos definitivos está pendente.
- Não altera dano, derrota, vida, lógica de ondas nem os inimigos Tipo 6 regulares.
- Não testado em navegador ou por npm build/test nesta sessão. Testar localmente: git pull, npm test, npm run build, npm run dev.
